# Convergene 设计系统（v0.2）

> 状态：P0 UI 事实源  
> 产品气质：清醒、利落、略带打工人式幽默的个人生产力工作台  
> 组件基础：[Arco Design React](https://arco.design/react/docs/start)

## 1. 使用方式

- 通用组件优先使用 Arco，不复制 Button、Form、Modal、Drawer、Tag、Progress 等基础组件。
- CSS Modules 只处理页面布局、React Flow 自定义节点、Markdown/Mermaid 容器和少量品牌化样式。
- 页面行为以 [UI 设计](../ui-design.md) 为准；领域状态以 [领域模型](../domain-model.md) 为准。
- 本文定义视觉 token 和跨页面规则，不替代页面规格。

## 2. 设计原则

1. **会中先看得清，再追求好看**：当前议题、计时和快捷输入永远高于装饰。
2. **卡牌感只用于“出招”**：提供轻微的可玩性，不引入牌组、能量、稀有度或胜负。
3. **AI 建议必须可拒绝**：建议与已保存事实有明确视觉差异。
4. **本地保存必须说清楚**：数据边界不是设置页里的隐藏条款。
5. **状态不只靠颜色**：文字、图标和形状共同表达。

## 3. 基础 Token

### 3.1 颜色

| 角色 | 值 | CSS 变量 | 用途 |
|---|---:|---|---|
| Primary | `#1D4ED8` | `--color-primary` | 主要操作、当前议题 |
| Primary subtle | `#DBEAFE` | `--color-primary-subtle` | 选中与聚焦背景 |
| Accent | `#D97706` | `--color-accent` | 计时、临门一问、超时提醒 |
| Success | `#15803D` | `--color-success` | 已保存、可以开了 |
| Warning | `#B45309` | `--color-warning` | 勉强能开、待确认建议 |
| Danger | `#DC2626` | `--color-danger` | 破坏性操作和失败 |
| Background | `#F8FAFC` | `--color-background` | 页面背景 |
| Surface | `#FFFFFF` | `--color-surface` | 卡片、面板、节点 |
| Foreground | `#0F172A` | `--color-foreground` | 主文字 |
| Muted foreground | `#475569` | `--color-muted-foreground` | 次级说明 |
| Border | `#CBD5E1` | `--color-border` | 默认边框 |
| Dimmed decoration | `0.34` | `--opacity-dimmed` | 非当前连接线等非文字装饰；不得作用于可读文本 |

会议剧本可以使用辅助色条，但不得改变组件语义：

- 决策对齐：蓝色；
- 脑暴共创：紫色；
- 复盘改进：青绿色；
- 通用讨论：中性灰。

### 3.2 字体

- 标题与正文：`Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "PingFang TC", "Microsoft YaHei", "Microsoft JhengHei", sans-serif`。
- 数字、时间、人时：`ui-monospace, "SFMono-Regular", Consolas, monospace`。
- 中文正文不依赖缺少 CJK 字形的 Web Font。
- 页面标题 24/32、区块标题 18/26、正文 14/22、辅助文字 12/18；画布节点最低 13/18。

### 3.3 间距、圆角与阴影

| Token | 值 | 用途 |
|---|---:|---|
| `--space-1` | `4px` | 图标与文字 |
| `--space-2` | `8px` | 控件内部 |
| `--space-3` | `12px` | 紧凑区块 |
| `--space-4` | `16px` | 标准卡片 |
| `--space-6` | `24px` | 页面区块 |
| `--space-8` | `32px` | 大区块 |
| `--radius-sm` | `6px` | Tag、输入框 |
| `--radius-md` | `10px` | 卡片、节点 |
| `--radius-lg` | `14px` | Drawer、重点面板 |
| `--shadow-float` | `0 8px 24px rgb(15 23 42 / 12%)` | 节点旁出招卡 |

## 4. 信息层级

跨页面固定层级：应用外壳只出现一次产品品牌；每页只有一个页面级 `h1`；页面标题说明任务，区块标题从 `h2` 继续。功能工具栏不重复 Logo、产品名或页面标题。

桌面会议工作台的固定优先级：

1. 顶栏：会议状态、计时、实际人数、总人时、结束会议；
2. 画布：当前议题分支；
3. 快捷输入：随手记；
4. 上下文操作：节点出招卡；
5. 右栏：节点详情、会议产出、主持人小抄。

不要让设置、云同步预告或报告装饰抢占会中主路径。

## 5. 核心组件规则

### 5.1 MeetingCard

- 显示标题、剧本、生命周期、时间状态、计划时间和本机保存标记。
- `LIVE` 会议有明确但不闪烁的状态条。
- 整卡可点击时才显示 hover；卡内删除使用独立按钮和二次确认。

### 5.2 ReadinessBar

- 使用分段进度，不展示 0–100 的伪精确数字。
- 三个标签固定为“信息不足／勉强能开／可以开了”。
- 每个准备维度可点击并有键盘焦点，用于指定下一轮 Grill。
- “继续拷问我”显示当前轮次与最多 10 轮，不制造焦虑倒计时。

### 5.3 MapNode

- 标题默认最多两行，超出省略，详情在右栏完整显示。
- 当前议题、选中节点、会议产出和 AI 建议使用不同边框/徽标组合。
- `kind = NOTE` 且 `source = QUICK_NOTE` 的随手记节点使用便签形态，但保持高对比度。
- 节点不能仅靠背景色表达类型。

### 5.4 StrategyCards

- 只在节点被选中时，靠近节点显示三个紧凑操作卡。
- 每张卡包含名称和不超过一行的解释；点击后显示局部 loading。
- 使用轻微层叠、边框与 `--shadow-float` 营造卡牌感，不使用翻牌、抽卡或稀有度动画。
- 浮层不能遮住所选节点、顶部栏或快捷输入；空间不足时转入右栏。

### 5.5 OutcomeBadge

- 四类固定图标＋文案：决策、候选创意、洞察、行动项。
- 行动项的负责人和日期是可选元数据，不呈现为企业任务流。
- 实现 ST-03 时，会后补记必须显示“会后补记”，形成成本显示为“不计入”。

### 5.6 LocalDataNotice

- 首页保持可见的“本机保存”说明；模型设置说明 Key 会被服务端加密保存。
- “导出全部数据”是可操作入口。
- “登录并开启云同步”在 P0 是带“即将支持”语义的转化入口，不能伪装成已完成能力。

## 6. 画布与动效

- 固定使用从左到右的单向树；根在左，一级议题按 `order` 排列。
- 只有显式切换议题、点击“重新聚焦”或“一览全图”才移动镜头。
- 切换议题时当前子树居中，其他分支降权；普通节点选择不改变当前议题。
- 常规控件动效使用 Arco 内置能力和 150–200ms CSS transition；当前议题镜头聚焦使用 200–300ms，不引入 GSAP。
- 新节点可淡入并轻微位移；计时和人时数字不做跳跃式动画。
- 遵守 `prefers-reduced-motion`，此时镜头直接定位。

## 7. 响应式边界

- 应用顶栏桌面高 `64px`、手机高 `60px`；手机端图标控件保持 44px 点击目标，并以可访问名称替代可见长标签。
- `>= 1024px`：完整画布、节点旁出招卡和右栏。
- `768–1023px`：压缩右栏，可用 Drawer；保留可读画布。
- `< 768px`：首页、Grill、计时、会议产出、报告和列表式议题为主；P0 不承诺完整可拖动画布。
- 必测宽度：375、768、1024、1440 px；英文和 200% 缩放不能挡住主要操作。

## 8. i18n 与内容

- 全局提供 `简体中文 / 繁體中文 / English`，不使用国旗代表语言。
- 所有可见文案必须来自词典；剧本、准备度、产出和策略使用稳定 ID。
- 切换界面语言不翻译或改写用户会议内容。
- 按英文长度设计按钮与 Tag，不使用固定文本宽度。
- 英文按单词换行，不在单词中间强制断字；Grid/Flex 子项显式允许收缩，不能用 `overflow: hidden` 掩盖任务内容。
- 调侃只出现在标题、空状态和辅助文案；确认、错误和数据边界使用直接措辞。

## 9. 可访问性

- 正文对比度至少 4.5:1；大字至少 3:1。
- 所有点击目标至少 44×44 px；紧凑画布控件至少提供等价键盘入口。
- 焦点样式可见；图标按钮必须有本地化 accessible name。
- Modal 打开后正确管理焦点，关闭后还给触发器。
- Mermaid 必须有文本标题和 Markdown/表格降级，报告不能只靠图传达事实。

## 10. 禁止模式

- 不在同一页面重复产品 Logo 或 `Convergene` 品牌锁定。
- 不在已有数据的任务页继续占用整屏 Hero；不把说明卡排在主表单或主结果之前。
- 不使用 emoji 代替功能图标；使用 Arco Icon SVG。
- 不使用会造成布局跳动的 hover scale。
- 不自动接受 AI 建议、不自动切换议题、不自动结束会议。
- 不把通用讨论做成与三种主剧本同等显眼的首页主入口。
- 不增加积分、能量、卡包、排行榜或企业成员管理。
- 不用 placeholder 代替表单 label，不用颜色作为唯一状态信号。
